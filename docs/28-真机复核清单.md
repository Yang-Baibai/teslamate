# 真机复核清单（v0.85.0 起）

> **为什么有这份清单**：2026-10-29 接上 USB 做真机复核时发现，
> 「模拟器能测什么、真机才能测什么」这件事每轮都在重新想。
> 而**版面类**问题如果不在模拟器上用**受控注入**造最坏情况，
> 就会一路拖到发版才暴露（这轮就抓到一个「左前窗开着」被砍成「左前窗开...」）。
>
> ⇒ 照着这份清单走，每轮只花十几分钟。

## 一、两台设备各管什么

| 设备 | 负责 | 不负责 |
|---|---|---|
| **模拟器** `emulator-5554` | **版面**：与真机同参数（1440×3200@600 = 384dp 宽）⇒ 版面问题在这里就能复现；还能用**受控注入**造最坏情况 | 系统级差异（ROM / 深色 / 真实网络） |
| **真机** `<真机序列号>` | **系统级**：真实 ROM（后台杀）、深色模式、真实网络路径（Tailscale / MagicDNS）、真实安装升级 | 造极端数据（慢、且不该在生产数据上动手脚） |

⚠️ 两台都在 ⇒ `adb` 必须显式 `-s <device>`，否则报「more than one device」。

## 二、每轮必做（模拟器，10 分钟）

1. **装最新版**：`adb -s emulator-5554 install -r -d <apk>`
2. **回顶**：`am force-stop` + `am start` + 往下滑到底（回顶脚本在
   `C:\Users\<用户名>\.minimax\tmp\tm_v084_shot.py`）
3. **受控注入最坏情况**（关键！）：
   - 起一个 mock（`127.0.0.1:8091`），只给 `/api/v1/cars/1/status` 注入最坏字段，
     **其余路径转发真实 API**；
   - `adb -s emulator-5554 reverse tcp:8090 tcp:8091`；
   - 启动 App ⇒ 截图 ⇒ **看有没有省略号截断**；
   - ⚠️ **测完必须**：`adb -s emulator-5554 reverse --remove tcp:8090`、
     `adb -s emulator-5554 reverse tcp:8090 tcp:8090`、**关掉 mock**。
4. **200% 字号**：`adb -s emulator-5554 shell settings put system font_scale 2.0`
   ⇒ 重启 App ⇒ 截图 ⇒ **看每一段文字是否都读得全** ⇒ **记得改回 1.0**
   （改字号会杀掉 App，属 Android 正常行为，不是崩溃）。
5. 换回真实数据再截一次（确认「没有异常时不多显示任何东西」）。

## 三、每轮必做（真机，10 分钟）

1. **装最新版**（真机上的旧版常常落后很多版，升级本身也是一次兼容性测试）；
2. **四个页签**逐个点开 + 截图（车况 / 记录 / 用量 / 设置）；
3. **深色模式**：`adb -s <真机> shell cmd uimode night yes` ⇒ 截图 ⇒
   ⚠️ **测完必须还原** `cmd uimode night no`；
4. **服务器状态页**（设置 → 服务器状态）：看「最后车况」「数据库」「实时状态」；
5. **不重装 App**（升级后配置应当自动沿用 —— 若没有沿用，那本身是个缺陷）。

## 四、什么该用真机查（模拟器查不到）

- **ROM 杀后台**：国产 ROM 会杀后台进程 ⇒ 依赖后台任务的功能（主动通知）必须真机验；
- **真实网络路径**：App 配的是 `<主机名>:8090`（**MagicDNS 直连**，不经 adb reverse）⇒
  外出时靠 Tailscale（手机上的 Tailscale **可能没连**）；
- **安装 / 升级 / 签名**：分发包换版前必须 `apksigner verify --print-certs` 比证书；
- **系统级交互**：深色模式、字体缩放、通知权限、后台存活。

## 五、踩过的坑（别再踩）

| 坑 | 真相 |
|---|---|
| `adb` 报「more than one device」 | 两台都在 ⇒ 显式 `-s <device>` |
| `adb shell input text` 之前必须 `input tap` | 不先点，文字进不去 |
| 手机 ping 不通 PC | **不代表 TCP 不通**（防火墙挡 ICMP）⇒ 用浏览器开 API 实测 |
| `aapt` 读 APK 报「找不到 AndroidManifest.xml」 | **路径有中文**（`%TEMP%` 也在中文用户目录下）⇒ 复制到 `C:\tm-app\` 这种纯 ASCII 路径 |
| `settings put font_scale` 之后 App 没了 | Android 的配置变更会**杀进程** ⇒ 不是崩溃，别误判 |
| uiautomator dump 偶尔只 dump 到桌面 | App 刚被 force-stop / 切到桌面 ⇒ 重启 App 再 dump |
| Python 内联命令里带中文路径 | PowerShell 会重编码 ⇒ **一律写临时 .py 文件** |
