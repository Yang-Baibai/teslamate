⚠️ **2026-11-13 就地订正（本节原写的许可证结论被实测证伪）**：

原表写「`grafana/dashboards/*.json`（23 个）来自 **MIT** 的 `teslamate-chinese-dashboards`」—— **这条不成立**，真因有两条：

1. **许可证不是 MIT，是 AGPL-3.0**。`wjsall/teslamate-chinese-dashboards` 的 `LICENSE` 正文是 **GNU Affero General Public License v3.0**
   （GitHub API 报 `NOASSERTION`，但文件正文是 AGPL-3.0；其 LICENSE 末段还明写「contains dashboard files derived from TeslaMate ... AGPLv3」）。
   ⇒ 若照原结论把整个仓库标成 MIT，就是**错误标注了 copyleft 文件**。
2. **那 23 个文件不是中文版的，是 TeslaMate 官方的英文原版**。逐字比对 `battery-health.json`：
   本地 61677 B vs 上游当前 62449 B ⇒ 本地是**更早的某个上游版本**，面板 ID / 标题 / SQL 全部一致。
   ⇒ 它们来自 **TeslaMate 本体**（AGPL-3.0），**不是**中文仪表盘项目；中文仪表盘**只以容器镜像**形式在运行时被使用。

⇒ **修法（已落地）**：仓库**自有代码 MIT**；`grafana/dashboards/` 下 23 个文件**明确排除在 MIT 之外**，
按 AGPL-3.0 原样再分发，仓库内附 AGPL 全文（`grafana/LICENSE-AGPL-3.0.txt`）＋ `NOTICE` 逐项署名。
