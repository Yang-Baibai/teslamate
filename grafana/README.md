## dashboards/*.json (23 files)

Archived copies of **TeslaMate's own Grafana dashboards** (the English
originals), copied verbatim from upstream and never edited since. They are
kept for reference only: they are **not** mounted into the running Grafana
container - the Chinese dashboard image
(`ghcr.io/wjsall/teslamate-chinese-dashboards:latest`) supplies the
dashboards that are actually served. See the comment in `compose.yaml`.
