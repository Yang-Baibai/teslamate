# ⚠️ v0.97.0：ⓘ 口径说明**超长**基线（每行一条：<视觉宽度>\t<文件>::<开头 16 字>）。
#
# ## 这份基线是什么
#
# ⓘ（InfoNote / TextWithNote / KeyValueWithNote / KV 的 note 参数）
# 是**用户主动点开**的详情 —— 点一下才展开，所以它可以比常驻说明详细。
# 但它也必须有**上限**：点开 ⓘ 期望得到「一句话结论 + 关键限定」，
# 不是一堵字墙。
#
# 仓库原有的「啰嗦棘轮」（闸门 5）只管**常驻可见**的长说明块 ——
# 文字一旦折进 ⓘ，闸门就看不见 ⇒ ⓘ 里的口径**没有长度上限**，
# 这正是 v0.96.0 CHANGELOG 的头号痛点。
#
# ⇒ 闸门 13 立了上限 `NOTE_WIDTH_LIMIT = 160`（视觉宽度 ≈ 80 个全角字 ≈ 展开 3 行），
#   这里的每一行 = 一次**有记录的决策**：它现在超限，但**只许变短、不许变长**。
#
# ## 怎么读这些数字
#
# 「视觉宽度」= 汉字/全角算 2 格、半角算 1 格（与闸门 5 同口径）。
# 数字多的句子最容易在手机上折行断句，只数汉字会漏掉它们。
#
